## What this book is

Most beginner Python books hand you syntax lists. This one hands you a working program by page four, then walks you through every part of it.

The goal isn't to memorize commands. It's to learn how to break a problem into small steps, test each step, and fix what goes wrong — a skill that outlasts any one language.

Examples are Minecraft/PvP themed (players, ranks, tournaments) so they're easy to picture. Every chapter includes runnable examples, hands-on exercises, and a full answer key.

## What's inside (Chapters 1–10)

1. **What Is Programming?** — what programming is, how computers follow instructions, what an algorithm is, and how to think like a programmer.
2. **Getting Started with Python** — installing Python, choosing an editor, checking your setup, and fixing common problems.
3. **Your First Python Programs** — `print()`, comments, syntax rules, reading error messages, and the interactive REPL.
4. **Values, Variables, and Names** — storing information, assignment, updating variables, and naming things clearly.
5. **Data Types and Type Conversion** — integers, floats, strings, Booleans, `None`, and converting between them.
6. **Input, Output, and User Interaction** — `input()`, `print()` formatting, clear prompts, and building interactive programs.
7. **Operators and Expressions** — arithmetic, floor division, modulo, precedence, and augmented assignment.
8. **Working with Text and Strings** — indexing, slicing, methods, f-strings, and a small text-processing project.
9. **Making Decisions with Conditions** — `if`, `elif`, `else`, `and`, `or`, `not`, and the mistakes that trip up beginners.
10. **Boolean Logic and Comparisons** — truth tables, short-circuiting, chained comparisons, and De Morgan's laws.

## Who it's for

- Absolute beginners who have never written a line of code.
- People who tried a tutorial once and bounced off.
- Anyone who wants a structured on-ramp to Python before moving on to projects or specialization.
